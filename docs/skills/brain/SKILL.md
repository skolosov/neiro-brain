# /brain

Личная база знаний пользователя живёт на MCP-сервере `neiro-brain`. Инструкции сервера
коротко описывают порядок работы, а полный протокол лежит на самом сервере и может
меняться. Поэтому:

1. Прочитай ресурс `knowledge://skill/brain` (MCP-сервер `neiro-brain`).
2. Дальше действуй строго по нему.

## `/brain compact`

То же самое, но с охватом: проект (`--project=<имя>`), тема или вся база.
Прочитай `knowledge://skill/brain`, раздел «Команда `/brain compact`», и выполни его:
найди дубли, покажи план слияния, дождись подтверждения, запиши объединённое
через `remember_many`, а старые карточки перечисли в поле `supersedes`.
